# Taislius's Homebrew tap

Formulae for [Podėlis](https://github.com/taislius/podelis), a terminal UI
SQL client for PostgreSQL, MySQL and SQLite.

```sh
brew install taislius/tap/podelis
```

Or `brew tap taislius/tap` once, then `brew install podelis`. Updates come
with `brew upgrade`.

Works on macOS and Linux (Homebrew on Linux), on x86_64 and ARM. The
formula installs the release binaries from
[GitHub releases](https://github.com/taislius/podelis/releases) and the
`podelis(1)` man page.
